# report: сводка для владельца

Аргумент (необязательный): период («за неделю», «с 1 октября») или тема («оценка звонков»). По умолчанию — последние 7 дней по этому проекту. Читатель — сам владелец. Для руководителя без технических деталей — `/demo-brief`.

Отчёт только читает. Файлы не меняются, если владелец не попросил сохранить отчёт.

## Источники

- `git log` за период — сгруппируй по результату для пользователя продукта, коммиты не пересказывай.
- Архив OpenSpec за период (`openspec/changes/archive`), их `verification.md`.
- `docs/status.md`, `docs/waiting.md`, `README.md`.
- Метрики проекта: логи, база, дашборды, отчёты. Только чтение и только бесплатные запросы.

## Форма (по-русски, обычным текстом)

1. **Итог** — 2–3 предложения: где проект сейчас и что главное за период.
2. **Что сделано** — по результату: что теперь умеет продукт или что стало лучше.
3. **Цифры** — таблица. У каждого числа источник, дата или период и статус: подтверждено | из старой записи | не проверено. Сравнение «было — стало», если есть с чем.
4. **Что сломано или под угрозой.**
5. **Что ждёт** — из `docs/waiting.md`: что, от кого, с какого числа.
6. **Что дальше** — 1–3 пункта.

Чего нет в источниках, не додумывай: пиши «нет данных» и где их взять.
