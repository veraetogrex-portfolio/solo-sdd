# context-resume: карта задачи до первого действия

Пользователь не должен переносить контекст между сессиями и агентами. Всё, что он уже сказал, решил или положил в `.env`, ты находишь сам. Результат — короткая карта задачи, по которой видно, что делать дальше.

## Порядок

1. **Правила проекта.** `AGENTS.md`, `CLAUDE.md`, `openspec/config.yaml`, `docs/status.md`, `docs/waiting.md`. Это источник истины о процессе.
2. **Передача.** `handoff.md` в папке активного change или в корне проекта, `verification.md` незакрытых change, `openspec list --json`.
3. **Текущее состояние.** `git status`, `git log -10 --oneline`, ветка, открытые PR, ключи в `.env` (только имена, значения не печатать), запущенные процессы. Для сервиса — что реально задеплоено: коммит, контейнер, таблицы.
4. **История.** Ищи по ключевым словам задачи, а не читай всё подряд. Источники по доступности:
   - пользователь дал живую ссылку на чат Codex: сначала `read_thread` для каждого такого чата; заголовок ссылки не заменяет содержимое;
   - поиск по чатам (`conversation_search`), если инструмент доступен; если его нет — локальные файлы истории ниже;
   - Claude Code: `~/.claude/projects/<папка-проекта>/*.jsonl`;
   - Codex: `~/.codex/memories/MEMORY.md`, `~/.codex/sessions/<год>/<месяц>/`;
   - Obsidian: начни с `000_INDEX.md` нужного волта.
   Инструмента нет — переходи к следующему источнику. Не выдумывай, что «в чатах было».
5. **Сверка.** Каждый факт из истории сверь с файлами и сервисом. Если они расходятся, верь текущему состоянию, а расхождение запиши.
6. **Карта** по форме ниже, затем сразу работа. Пользователь просил только восстановить контекст — останавливаешься на карте.

## Карта (по-русски, без вступления)

```
Цель: <что должно получиться, одной фразой>
Источник истины: <файлы, сервис, таблица, на которые опираюсь>
Последнее подтверждённое состояние: <что проверено и где, с датой>
Решения и ограничения: <что пользователь уже решил или запретил>
Блокеры: <что ждём и от кого> | нет
Следующий шаг: <одно действие>
Расхождения истории и факта: <что устарело> | нет
```

## Завершение работы

Если правила проекта ведут `handoff.md` или `docs/status.md`, обнови их той же картой. Глобальную память (Obsidian, память агента) меняй только по прямой просьбе.

## Ошибки

| Мысль | Что делать |
|---|---|
| «Спрошу у пользователя, где ключ» | Сначала `.env`, история, соседние сервисы |
| «В чате было написано, что готово» | Проверь в коде и на сервисе |
| «Прочитаю всю историю, чтобы ничего не упустить» | Ищи по словам задачи, история дорогая |
| «Создам рабочую копию рядом» | Папка проекта одна, работай в ней |
| «Старая заметка в Obsidian верна» | Заметка — гипотеза, пока не сверена |
| «Независимая новая задача, но поищу в истории» | Не тяни чужой контекст в новую задачу |
